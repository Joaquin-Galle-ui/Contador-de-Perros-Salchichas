# Seguridad

No publiques credenciales, claves de firma, tokens, URLs operativas privadas ni el archivo `google-services.json`.

Si una credencial llega a un commit, borrarla en un commit posterior no es suficiente: revócala o rótala en el servicio correspondiente y limpia el historial antes de publicar.

La versión de muestra debe conservar únicamente marcadores como `TU_PROYECTO`, `TU_TEMA_PRIVADO` y `TU_IMPLEMENTACION`.
